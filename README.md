# 丝链智盾（SilkChain Guard）

面向中国—东盟跨境业务的本地化单证智能中台。作品不采用多租户 SaaS，围绕“纸质凭证保留、电子数据提效、企业内网管控”完成资料归档、标准统一、全链核验、异常处置与价值测算。

## 作品定位

- **纸电并行**：纸质原件承担签章、背书、交付和争议举证；电子副本承担检索、比对、协同和预警。不以“一夜无纸化”为前提。
- **统一单证标准**：以企业编号、目录、字段字典和版本记录统一采购、仓储、运输、报关、交付与结算资料。
- **实物、系统、单证一致**：沿订单—入库—装运—报关—签收—结算六个环节核对数量、金额、批次、日期、主体和贸易术语。
- **本地化部署**：网页、资料库、规则库和模型网关可运行在企业内网，原始单证不必发送给第三方 SaaS。
- **人机协同**：AI 给出证据、风险解释和处置建议，高风险放单与合规结论必须由授权人员复核。

## 当前可演示能力

- 企业单证包编号、四级目录、纸质/电子双轨台账与相似案例回忆
- 对标 DA/T 13、DA/T 22、GB/T 18894、DA/T 31、DA/T 94 的档号、电子文件名、纸质标签同源生成
- 纸质原件位置与电子文件版本、SHA-256 校验、保管期限双向映射，支持导出归档清册
- 商业发票、装箱单、海运提单、报关单、原产地证、签收单适配展示
- 跨单证规则核验、风险评分、实物与系统差异定位、放单冻结
- FOB、B/L、HS Code、“三单一致”等术语白话解释和风险举例
- 人工核单与异常损失年度节省金额计算
- 本地模型建议入口、数据脱敏、权限控制、提示注入拦截和审计留痕
- TXT/CSV 字段提取；PDF/图片保留 OCR 接入位置

## 为什么保留纸质单据

跨境业务涉及不同国家、港口、银行、承运人与监管部门，数字化接受程度并不一致。纸质正本在部分提货、背书、盖章和争议场景中仍有现实作用。丝链智盾采用渐进式方案：先建立电子索引和一致性核验，再按国家、单证类型和合作方逐步切换电子原件，避免因盲目无纸化造成凭证失效或交付中断。

## 参考依据

- ICC Digital Standards Initiative：跨境交易平均涉及 36 份单证、240 份副本，完全数字化比例不足 1%。
- UN ESCAP：无纸贸易改革可将出口时间降低 24%—44%，直接成本降低 17%—31%。

上述行业数据用于说明市场问题，不代表本原型已经达到相同效果；识别率、召回率和节省金额需使用企业脱敏样本进行验证。

## 本地运行

仅浏览静态演示，可直接打开 `dist/index.html`。

启用本地模型建议时：

1. 在企业电脑或服务器运行 OpenAI 兼容的本地模型服务，例如本地部署的 DeepSeek 模型。
2. 在项目根目录执行 `node dist/local-server/server.mjs`。
3. 浏览器访问 `http://127.0.0.1:8787`。

默认模型接口为 `http://127.0.0.1:11434/v1/chat/completions`，默认模型名为 `deepseek-r1:7b`。可通过 `MODEL_BASE_URL`、`MODEL_NAME`、`MODEL_API_KEY`、`HOST` 和 `PORT` 环境变量调整。详细说明见 `dist/local-server/README.md`。

公开 Sites 版本通过服务端 `/api/analyze` 代理访问 DeepSeek，浏览器端不保存密钥。托管环境变量使用 `DEEPSEEK_API_KEY`、`DEEPSEEK_BASE_URL` 和 `DEEPSEEK_MODEL`；默认模型为 `deepseek-flash`。服务端执行同源检查、结构化输入白名单、每 IP 每分钟 6 次的尽力限流及 25 秒超时，并且所有结论仍需人工复核。

任何密钥都只应保存在本地服务环境变量中，不得写入网页、GitHub 仓库或 `dist/config.js`。

## 比赛版验证计划

1. 用脱敏真实单证建立训练集、验证集和异常案例库。
2. 分别测试扫描件、手机照片、电子 PDF 的字段准确率与异常召回率。
3. 记录人工复核时间、漏审率、改单损失和部署成本，形成可审计的投入产出报告。
4. 增加身份认证、数据库加密、文件查毒、备份恢复和自动删除策略。

静态演示入口：`dist/index.html`。
