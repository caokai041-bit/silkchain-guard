# 丝链智盾（SilkChain Guard）

面向中国—东盟跨境订单的 AI 单证审核与履约风险决策平台原型。

## 当前可演示能力

- 一键装载采购订单、商业发票、装箱单、海运提单脱敏样例
- 真实运行的前端跨单证规则核验与风险评分
- 数量、金额、贸易术语、装运期限异常定位
- OCR → 跨单证核验 → LLM/RAG 决策 → 安全护栏协同链路展示
- 数据、模型、应用三层安全中心及可操作的防护测试
- 风险处置任务生成、审计留痕、脱敏报告导出
- TXT/CSV 文件字段提取；PDF/图片已预留 OCR 服务接入位置

## 比赛版下一阶段

1. 将 `dist/app.js` 中的浏览器字段提取替换为真实 OCR 服务。
2. 接入大语言模型和供应链规则知识库，所有结论返回证据片段。
3. 增加服务端身份认证、数据库加密、文件查毒和自动删除任务。
4. 使用脱敏真实单证完成准确率、召回率、延迟与安全测试。

静态原型入口为 `dist/index.html`。
